Portfolio

Expert Advisor · MQL5

Multi-symbol EA: one chart — multiple instruments

The EA is installed on the chart of any instrument, but trades 4–6 symbols simultaneously, specified in the settings. The charts of these instruments don't need to be open — the robot fetches quotes itself, performs analysis, and independently manages positions for each symbol. Inside is a unified architecture where each instrument is serviced by its own logic: its own signals, its own risk management, its own trailing stop. Robots of this class have been running in the client company's live trading for several years.

Indicator · MQL5

SwingFractals — fractals without the "noise"

Swing extremes indicator for MT5. Unlike Bill Williams' standard fractals, it discards consecutive same-type signals and keeps only the significant ones: between two upper ones — the highest, between two lower ones — the lowest. The output is an alternating sequence of upper and lower extremes, convenient for swing marking and building "level to level" strategies. The number of confirming candles is configurable.

Infrastructure · MQL5

Remote auto-update for an Expert Advisor

A mechanism where the robot periodically polls the server and checks whether a new version has been released. If an update is available, it downloads it and restarts on the chart without user intervention. Positions and state are preserved. Used in several projects where it was important to update a fleet of client robots centrally, without logging into each terminal manually.

Testing · Research · MQL5

Strategy validation from any point in history

The Strategy Tester only starts the robot from the beginning of the day — you can't start mid-day and see how the strategy behaves under different conditions. And in live trading this is critical: two users who launched the same robot at different times of day may get completely different results. For one project, I built a system that allows checking each signal of a trading strategy — including those that the regular tester simply doesn't process. In the client's robot, the tester recorded about 5,000 signals, while in reality there were more than 45,000. The system allowed running all 45,000 and confirming the strategy's viability over a ten-year history period — without the "blind spots" that usually cause discrepancies between backtest and live trading.
